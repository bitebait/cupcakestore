Gerenciar as Configurações do Pix

O código Pix é gerado aqui na loja. A confirmação do recebimento é feita pela equipe após conferir a transação no banco.

Use o nome da pessoa ou empresa que receberá o Pix, com até 25 caracteres.

Para chave de celular, informe o código do país: +55 seguido do DDD e número. Para CPF, use somente números. Informe o CNPJ como está cadastrado; ele pode conter letras.
